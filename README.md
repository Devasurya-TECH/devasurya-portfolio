# Devasurya M — Portfolio

A story-driven portfolio for **Devasurya M**, an AI/ML & Software Engineering Trainee based in Kochi, India.

This site presents more than a skills list. It follows the path from software-development foundations, through data and machine learning, to the goal of building useful AI products that people can trust.

## Highlights

- Editorial scrapbook visual language inspired by notebooks, research boards, and product sketches
- Personal photo-led introduction and career story timeline
- TalentIQ featured as the flagship AI-powered employee analytics project
- Real technology logos for the tools studied: Python, NumPy, Pandas, scikit-learn, Django, PostgreSQL, Git, Jupyter, GitHub, and Bootstrap
- Custom ML analytics workbench with an illustrative trend chart, workflow map, and product-thinking callout
- Responsive layout and accessible labels for image and icon content
- Direct links to GitHub, LinkedIn, LeetCode, Instagram, and email

## Tech

Built with semantic HTML, CSS, and a small vanilla JavaScript mobile-navigation enhancement. Technology marks are loaded from the [Simple Icons CDN](https://simpleicons.org/).

## Run locally

No install is required. From the project directory:

```bash
python -m http.server 4173
```

Then open `http://localhost:4173`.
